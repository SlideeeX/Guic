Установка библиотеки:

1. Выгрузить содержимое папки в папку с проектом. В папке с проектом обязательно должны быть файлы dll. Папку Guic можно расположить в системе
в удобном месте.
2. Далее необходимо сообщить компилятору, где найти заголовки (файлы .hpp), а компоновщику - библиотеки (файлы .a).
Для этого во вкладке project - build options - search directories:
На вкладке Compiler указать путь к файлам включения (".../Guic/include")
На вкладке Linker указать путь к библиотекам (".../Guic/lib")

3. В линковщике на вкладке "Linker settings" в Link libraries указать:

guic-base
sfml-graphics
sfml-window
sfml-system

В GCC важно соблюдать порядок, указанный выше, т.к. сверху указываются библиотеки, которые зависят от тех, что ниже.

5. В main.cpp теперь необходимо подключить необходимые заголовочные файлы. Файл BaseGUIC.hpp содержит все базовые классы.

Файл Settings.hpp содержит настройки по умолчанию, можно подключить перед подключением BaseGUIC.hpp.

------------------------------------------------------------------

Installing the library:

1. Upload the contents of the folder to the project folder. There must be dll files in the project folder. The Guic folder can
be located in a convenient location on the system.
2. Next, you need to tell the compiler where to find the headers (files.hpp), and libraries (.a files) to the linker.
To do this, in the project - build options - search directories tab:
On the Compiler tab, specify the path to the inclusion files (".../Guic/include")
On the Linker tab, specify the path to the libraries (".../Guic/lib")

3. In the linker, on the "Linker settings" tab in Link libraries, specify:

guic-base
sfml-graphics
sfml-window
sfml-system

In GCC, it is important to follow the order indicated above, because libraries that depend on those below are indicated at the top.

5. In main.cpp now you need to connect the necessary header files. The BaseGUIC file.hpp contains all the base classes.

The Settings.hpp file contains default settings that can be connected before connecting BaseGUIC.hpp.
